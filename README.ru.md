# WoWee для PSP

[English](README.md) | **Русский**

**Нужна помощь? Заходите в Discord Sandstone_PSP: [discord.gg/wV8x46ZTDu](https://discord.gg/wV8x46ZTDu)**

**Впервые здесь? Идите по [пошаговой установке](#пошаговая-установка)** — от клиента на ПК до первого входа на PSP.

Порт игрового клиента [WoWee](https://github.com/Kelsidavis/WoWee) на Sony PSP-2000 и PSP-3000. Работает с
**World of Warcraft 3.3.5a (сборка 12340)**, который должен быть у вас свой: в этом репозитории нет игровых данных.
Свой клиент вы конвертируете на ПК программой **[Kiln](https://github.com/SandstoneDev/Kiln)**.

> Проект не связан с Blizzard Entertainment и Sony Interactive Entertainment и не одобрен ими. World of Warcraft,
> PSP и PlayStation — товарные знаки своих владельцев; они названы здесь только чтобы сказать, с чем работает порт.

## Что нужно

- **PSP-2000 или PSP-3000** в режиме 64 МБ (`MEMSIZE=1` в `PARAM.SFO`). Проверено только на PSP-3000. PSP-1000
  (32 МБ) не поддерживается.
- PSP, на которой запускается homebrew, с включённой для homebrew дополнительной памятью этих моделей. Этот проект
  не даёт, не ссылается и не объясняет такие прошивки.
- Свой клиент **World of Warcraft 3.3.5a (12340)** на ПК, сконвертированный Kiln (проверены enUS и ruRU).
- Карта памяти с местом под данные (около 17 ГБ на полный набор). Карта в FAT32: ни один файл не может быть больше
  4 ГБ.
- Wi-Fi и сервер 3.3.5a, к которому вам разрешено подключаться (см. [Серверы](#серверы)).

## Состояние

В разработке; играбельно на приватном сервере AzerothCore.

- **Мир:** подгружаемые земля, объекты и здания всех четырёх континентов, подземелья и рейды, переходы между
  картами с экранами загрузки, транспорт (корабли, дирижабли, лифты), небо и освещение, погода и частицы.
- **NPC и игроки:** модели существ и персонажей с анимацией и экипировкой; маунты; полёты и плавание.
- **Игра:** бой и заклинания, цели, добыча, инвентарь и сумки, торговцы, учителя, таланты, задания, почта,
  аукцион, обмен, группы и рейды, очередь на поля боя, поиск подземелий, календарь, достижения, банк гильдии.
- **Интерфейс:** нарисован из графики и строк вашего же клиента (их конвертирует Kiln), разложен под 480x272 и
  кнопки PSP; миникарта, карта мира, обучение, ролики.
- **Языки:** язык вашего клиента (проверены enUS и ruRU). Если сконвертировано несколько языков, язык выбирается
  на экране входа или в меню настроек.
- **Вход:** логин и пароль вводятся на экране входа экранной клавиатурой PSP. Первый успешный вход сохраняется вне
  папки игры (`ms0:/WOWEE/account.dat`: хэш, а не пароль, привязанный к вашей консоли), поэтому скопированная
  папка игры никогда не несёт ваш аккаунт.
- **Безопасность на публичных серверах:** все отладочные функции и автоматизация работают только когда сервер —
  частный адрес из `devhosts=`; никакой ключ настроек не включает их на публичном адресе.

Известные пробелы: вода пока не рисуется; часть карт подземелий на карте мира показывает заглушку.

На PSP-3000 порт идёт примерно на 28 fps (медиана, с загрузками) и использует около 41 МБ памяти под игру.

## Управление

Две схемы, которые следуют за оружием персонажа: **Путь** (оружие в ножнах) и **Бой** (оружие в руках). Вход в бой
переключает на Бой; через несколько секунд после боя (`sheathdelay=`, по умолчанию 5 с) порт возвращается в Путь.
Вниз на крестовине переключает вручную. Переключение видно по анимации и звуку оружия, скрещённым мечам у рамки
игрока, значкам кнопок на панели действий и короткой жёлтой строке.

### Всегда

| Кнопка | Действие |
|---|---|
| Аналог | движение относительно камеры (слегка — шаг, до упора — бег) |
| R (держать) + аналог | поворот камеры; отпустили — камера возвращается за спину |
| R + Вверх / Вниз | приближение |
| Вниз | достать / убрать оружие (смена схемы) |
| Влево / Вправо | предыдущая / следующая цель (в Бою — только враги) |
| Вверх | взаимодействие: говорить, обыскать, открыть |
| L + R | автобег вкл / выкл |
| SELECT | курсор и окна (режим интерфейса) |
| HOME | выход (или Меню → Выход) |

### Путь (оружие в ножнах)

| Кнопка | Действие |
|---|---|
| ✕ | прыжок |
| ○ | сесть / встать |
| □ | снять цель |
| △ | маунт |
| L + □ △ ○ ✕ | кнопки действий 1-4 |
| START | игровое меню |

### Бой (оружие в руках)

| Кнопка | Действие |
|---|---|
| □ △ ○ ✕ | кнопки действий 1-4 |
| L + □ △ ○ ✕ | кнопки действий 5-8 |
| R + □ △ ○ ✕ | кнопки действий 9-12 |
| START | прыжок |

### Окна (после SELECT)

| Кнопка | Действие |
|---|---|
| ✕ | левый клик: нажать, взять / положить предмет |
| ○ | правый клик: надеть, использовать, продать / купить |
| □ | взять / положить предмет; на заклинании — взять его на курсор |
| START | закрыть верхнее окно (нет окон — игровое меню) |
| R + аналог | двигать окно |
| L (держать) + △ на предмете | примерочная |
| SELECT | выйти из режима интерфейса |

## Пошаговая установка

Вашего времени уйдёт около часа, времени ПК — несколько часов (полная конвертация клиента заняла около 4 часов на
настольном ПК). Ваш клиент ничто здесь не меняет: Kiln его только читает.

### 1. Скачать

- **Порт:** `WoWeePSP-<версия>.zip` со страницы Releases этого репозитория. Внутри папка игры `WOWEEPSP/` с
  `EBOOT.PBP`, `sdbg.prx` (пишет отчёт, если игра упадёт), `Data/` (таблицы протокола) и `wowee.cfg.example`.
- **Конвертер:** `Kiln-<версия>-win64.zip` со [страницы Releases Kiln](https://github.com/SandstoneDev/Kiln).
  Распакуйте куда угодно; установка не нужна, Python уже внутри.

### 2. Сконвертировать клиент в Kiln

1. Запустите `Kiln.exe`.
2. **1 Your game folder** — *Browse...* и выберите папку клиента World of Warcraft 3.3.5a (12340): ту, где лежат `Wow.exe` и
   папка `Data`. Kiln сразу проверит её и покажет сборку и найденные языки. Клиент из раздачи приватного сервера
   подходит, если это 3.3.5a 12340.
3. **2 Extra languages** — не обязательно. Оставьте пустым, если у вас нет второй копии клиента на другом языке.
4. **3 Where to put it** — выберите одно:
   - **PSP memory stick** — подключите PSP по USB (*Настройки → USB-соединение* на PSP) или вставьте карту в
     кардридер, нажмите *Refresh*. Kiln всё сделает на ПК и в конце скопирует на карту.
   - **A folder on this PC** — на карту вы копируете сами (см. шаг 3 ниже).
5. *Advanced settings* — не обязательно, но рекомендуется:
   - **Your EBOOT.PBP of the port** — укажите `EBOOT.PBP` из zip порта. Kiln сделает копию с иконкой и фоном меню
     из графики вашего клиента (`xmb\EBOOT.PBP` в папке результата) и положит её на карту.
   - **Server** — уже заполнено `logon.therawow.com` (публичный сервер 3.3.5a), чтобы игра сразу работала. Для
     другого сервера впишите его адрес realmlist (`адрес:порт`, если порт не 3724). Kiln запишет его в `wowee.cfg`.
   - Рабочей папке нужно около 10 ГБ на быстром локальном диске; сами данные — около 17 ГБ.
6. Нажмите **Start**. На вкладке *Steps* видны все шаги, в строке состояния — сколько осталось. В конце вкладка
   *Summary* покажет общее время и где всё лежит. Отменённый или упавший прогон продолжается с того же места, если
   снова нажать *Start*.

### 3. Положить на карту памяти

Если Kiln копировал на карту — только проверьте папку. Иначе скопируйте вручную. На карте должно быть так:

```
ms0:/PSP/GAME/WOWEEPSP/
  EBOOT.PBP        EBOOT порта - лучше тот, что с графикой вашего клиента, из папки xmb\ Kiln
  sdbg.prx         из zip порта
  wowee.cfg        ваши настройки (Kiln пишет его, если вы указали сервер; иначе скопируйте wowee.cfg.example)
  data/            папка data\ из результата Kiln (около 17 ГБ, 1300+ файлов) вместе с Data/ из zip
```

- В `data/client/` лежит исполняемый файл вашего клиента, его копирует Kiln. Не удаляйте: серверы с античитом
  (Warden) проверяют клиент через него, и без него такой сервер перестаёт отвечать (игроки показываются как `?`,
  имена NPC — точками).
- `data` и `Data` из zip — одна и та же папка (карта памяти не различает большие и маленькие буквы): их содержимое
  просто складывается вместе.
- Карта в FAT32: ни одного файла больше 4 ГБ. Kiln уже делит то, что было бы больше.
- 17 ГБ по USB PSP копируются 30-40 минут. Когда PSP засыпает, она обрывает USB-соединение: подключите зарядку и
  поставьте *Настройки → Настройки энергосбережения → Автоматический переход в режим ожидания* на *Выкл*, прежде
  чем начать. Кардридер быстрее. После оборванного копирования скопируйте снова с пропуском одинаковых файлов или
  дайте Kiln найти и исправить недостающие и обрезанные файлы кнопками *Check integrity* и *Repair*.

### 4. Указать сервер

Kiln по умолчанию пишет `server=logon.therawow.com`; чтобы играть там, этот шаг можно пропустить. Для другого
сервера откройте `wowee.cfg` (в `PSP/GAME/WOWEEPSP/` на карте) Блокнотом и поменяйте единственную обязательную строку:

```
server=logon.therawow.com
```

Берите адрес, который сайт сервера даёт для realmlist (`set realmlist ...` без `set realmlist`). Если порт не 3724,
добавьте отдельной строкой `port=`. У всего остального есть значения по умолчанию; см.
[справочник wowee.cfg](#справочник-woweecfg).

### 5. Первый запуск

1. Запустите **WoWee PSP** из меню PSP *Игра → Memory Stick*. Любая кнопка пропускает стартовый экран.
2. На экране входа выберите поле аккаунта и поле пароля: для каждого откроется клавиатура PSP.
3. Выберите **Вход**. Откроется **системное окно выбора сети** PSP: выберите Wi-Fi, через которую есть интернет
   (её нужно заранее сохранить в *Настройки → Настройки сети* на PSP; домашние сети WPA2 работают). Кружок —
   отмена.
4. Порт подключится, войдёт и покажет миры, а затем ваших персонажей.

Первый успешный вход сохраняется на карте вне папки игры (`ms0:/WOWEE/account.dat`): хэш, а не пароль; работает
только на этой PSP и только для этого сервера. Следующие запуски входят без ввода. Чтобы войти другим аккаунтом,
введите его поверх сохранённого; чтобы забыть вход, удалите `ms0:/WOWEE/account.dat`.

## Меню настроек

В мире: **START** (в схеме Путь) открывает игровое меню; его первая кнопка (*Изображение* в русском клиенте,
*Video* в английском) открывает настройки. Вверх / Вниз — выбор строки, Влево / Вправо или ✕ — изменить значение,
подсказка под строками объясняет, что она делает, **Закрыть** сохраняет в `wowee.cfg`.

| Строка | Ключ `wowee.cfg` | Значения (по умолчанию) | Что делает |
|---|---|---|---|
| Дальность моделей | `m2view` | 40-240 ярд (160) | деревья, здания и мелкие объекты дальше не рисуются |
| Дальность игроков | `playerview` | 30-200 ярд (120) | другие игроки дальше не рисуются |
| Игроков на экране | `playermax` | 5-50 (10) | рисуются только ближайшие игроки; меньше — плавнее в городах |
| Дальность NPC | `npcview` | 20-150 ярд (70) | существа дальше не рисуются |
| Количество NPC | `npcmax` | 0-64 (24) | сколько ближайших существ рисовать |
| Пол | `terrainsharp` | AUTO / Чёткий (AUTO) | фильтрация текстуры земли; AUTO дешевле |
| Дальность чёткого пола | `sharpdist` | 30-240 ярд (120) | докуда земля остаётся чёткой (только «Чёткий») |
| Деталь земли | `terraindetail` | вкл / выкл (вкл) | детальная текстура земли вблизи |
| Лимит кадров | `framecap` | 30 / 60 (60) | 30 — ровный темп вместо скачков между 60 и 30 |
| Предсказание игроков | `remotepredict` | вкл / выкл (вкл) | плавнее движение других игроков по Wi-Fi |
| FPS и пинг | `perfhud` | вкл / выкл (выкл) | кадры в секунду и пинг до сервера у миникарты |
| AFK: сесть через | `afksit` | выкл-600 с (300) | персонаж садится, если столько времени нет ввода |
| Цели (вправо) | `targetall` | Только враги / Все | что перебирают Влево / Вправо |
| Автосбор добычи | `autoloot` | вкл / выкл (выкл) | обыск забирает всё сразу |
| Музыка / Звук | `musicvol` / `sfxvol` | 0-100 % (30 / 100) | громкость |
| Language | `locale` | сконвертированные языки | нужен перезапуск |

В людных местах (столица, стартовая зона загруженного сервера) в первую очередь уменьшайте **Игроков на экране**
и **Количество NPC**.

## Справочник wowee.cfg

`wowee.cfg` — обычный текстовый файл рядом с `EBOOT.PBP`: по одной строке `ключ=значение`, `#` начинает комментарий.
Меню настроек само пишет туда свои ключи; руками нужно править только ключи ниже.

| Ключ | По умолчанию | Значение |
|---|---|---|
| `server=` | `logon.therawow.com` (Kiln; встроенный `127.0.0.1`) | адрес realmlist: IP или имя хоста |
| `port=` | `3724` | порт realmlist |
| `netdialog=` | `1` | `1`: системное окно выбора сети при входе. `0`: подключаться к сохранённой сети самому (`netprofile=`) |
| `netprofile=` | `0` | при `netdialog=0`: номер сохранённой сети PSP; `0` — выбрать автоматически |
| `locale=` | от Kiln | язык, например `ruRU`; обычно меняется в меню настроек |
| `framecap=` | `60` | `60` или `30` |
| `perfhud=` | `0` | `1` — fps и пинг у миникарты |
| `playermax=` | `10` | сколько других игроков рисовать (5-50) |
| `devhosts=` | `127.0.0.1,localhost` | частные тестовые серверы, на которых работают отладочные функции; публичные адреса всегда игнорируются |

Аккаунт и пароль в `wowee.cfg` никогда не хранятся. Никому не отдавайте `session.log` (в нём ваш сервер и
персонаж) и папку `data/`.

## Если что-то не работает

- **«Wi-Fi: подключение не выбрано»** — окно выбора сети закрыли. **«Нет сохранённой Wi-Fi сети»** — сначала
  сохраните сеть в *Настройки → Настройки сети* PSP. **«Выключатель WLAN в положении OFF»** — сдвиньте
  переключатель на боку PSP.
- **Сервер недоступен** — проверьте `server=` и `port=` в `wowee.cfg` и что выбранная Wi-Fi выходит в интернет.
- **Игра закрывается при загрузке мира или зависает в толпе** — PSP не хватает памяти. Уменьшите *Игроков на
  экране* и *Количество NPC*. Пришлите в Discord `PSP/GAME/WOWEEPSP/session.log` и `CRASH.TXT` (если он есть).
- **Не хватает графики, чёрное окно или ошибки «pak» в `session.log`** — какой-то файл дошёл до карты не целиком.
  Запустите в Kiln *Check integrity*, затем *Repair*.
- **Иконка в меню PSP обычная** — вы взяли EBOOT из zip; возьмите тот, что в папке `xmb\` Kiln.

## Серверы

Порт — совместимый клиент: он старается вести себя как оригинальный клиент 3.3.5a и не даёт игрового преимущества.
Проверялся только на приватном сервере AzerothCore.

- **Спросите, прежде чем подключаться.** Многие серверы сообщества запрещают сторонние и изменённые клиенты и
  банят их автоматически. Прочитайте правила сервера и сначала спросите администрацию; за аккаунт отвечаете только
  вы.
- Отладочные функции работают только на частных серверах разработки (см. `devhosts=`).
- Не входите аккаунтом, который не готовы потерять.

## Сборка

EBOOT собирается [pspdev](https://github.com/pspdev/pspdev) (GCC 15.2) под Linux или WSL.

```bash
bash tools/psp/cloud_setup.sh          # один раз, на Linux без pspdev: ставит его в ~/pspdev
bash tools/psp/build_psp.sh --no-bump  # из Git Bash (перезапускает себя в WSL) или из Linux
```

Скрипт собирает чистую копию в `$HOME`, падает на любом `stubs out of order` и пишет `EBOOT.PBP` и
`wowee_psp.debug.elf` в `psp/bin/`. `MEMSIZE 1` задан в `psp/CMakeLists.txt`. Стартовый экран сообщества можно
убрать флагом `-DWOWEE_PSP_SPLASH=OFF`.
