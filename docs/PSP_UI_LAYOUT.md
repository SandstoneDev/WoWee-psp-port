# Classic UI restored

The optional PSP replacement UI has been removed at the user's request. The client always uses the existing Classic HUD, spell bar, menu, quest tracker and movable bag/bank windows. There is no Interface layout setting. Obsolete uilayout=1 entries are ignored. Rebuild EBOOT.PBP; no UI pack rebuild or menuicons.pak is needed.

Existing controller navigation, button symbols, window management, item actions, keyboard language/responsiveness, achievement reload, fog and performance fixes remain.
